## Project Vision (Refined)

A community-driven wiki for institutional processes (tax, licenses, permits). The MVP is a demo/prototype built with **React and Supabase**, allowing the general public to find, follow, and contribute detailed guides.

## Core Features (MVP)

1. **Search & Discovery**
   - Must-have filters: Keyword search, Category browse, Institution browse, Region filter.
   - Support for multiple alternative guides for the same process (e.g., variations by city/state).
2. **Comprehensive Guide View**
   - Mandatory Process Fields: Title, Institution, Region, Prerequisites, Documents, Fees, Deadlines, Estimated Time, Contact links.
   - Required Step Fields: Title, Description, Docs per step, Cost, Duration, Online/Offline indicator, Location/URL, and **Source Reference Link**.
3. **User Workflow**
   - Guest access (use guides without account).
   - Saved progress (cross-session tracking via Supabase auth).
   - Export: Print/Download checklist functionality.
4. **Contribution & Moderation**
   - Public contribution: Any user can upload/edit.
   - Moderation: "Auto-publish then report" flow.
   - Transparency: Version history visible to both admins and users.
5. **Internationalization**
   - Multilingual support (framework in place for the UI and content).

## Technical Stack

- **Frontend:** React (likely with a UI library for rapid prototyping).
- **Backend/DB:** Supabase (Auth, Database, Storage for docs if needed).
